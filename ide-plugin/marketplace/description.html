DroidLens lets you debug a running Android debug build without leaving Android Studio: an in-IDE network inspector (OkHttp, gRPC, WebSocket) and a lightweight layout inspector that jumps straight to the code that created a view. No proxy, no CA certificate, no web page.

⚠ Your app needs the DroidLens SDK. This plugin only displays the data; the capturing is done inside the app by a small runtime that the Gradle plugin adds to debug builds only. Without it, the app does not show up in the app list. See Setup below; it takes two Gradle edits and no code changes.

Network

  • Application-layer capture: HTTPS in plain text (before encryption / after decryption), unaffected by certificate pinning.
  • OkHttp requests with headers, bodies, TLS version, timing; gRPC calls with metadata, status and every streaming message; WebSocket frames in both directions.
  • JSON / text / hex / image viewers; protobuf decoding by field number, or by field name when a descriptor set is bundled.
  • Copy as cURL. Sensitive headers, tokens and passwords are redacted on the device before they leave the app.

Layout

  • Screenshot + View tree of every window (Activity, Dialog, PopupWindow), and the semantics tree of Jetpack Compose screens.
  • One click to the source: where a view was created, where its click / long-click / touch listener was set, the layout XML it was inflated from, where a Dialog was shown, its Fragment and Activity.
  • Edit properties live: text, visibility, alpha, padding, margin, size, colors, translation, scale.
  • Measure the spacing between two views (Shift + click).
  • Captures on demand only, no continuous streaming, so it stays fast on slow machines (a typical screen takes under 100 ms on the device).

Setup (required)

1. settings.gradle(.kts): add the repository in both places (the Gradle plugin resolves from pluginManagement, the runtime AAR from dependencyResolutionManagement).

pluginManagement {
    repositories {
        maven { url = uri("https://raw.githubusercontent.com/kakakakacat/android-helper/main/mvn-repo/") }
        gradlePluginPortal()
        google()
    }
}
dependencyResolutionManagement {
    repositories {
        maven { url = uri("https://raw.githubusercontent.com/kakakakacat/android-helper/main/mvn-repo/") }
        google()
        mavenCentral()
    }
}

2. App module:

plugins {
    id("kakacat.android.helper") version "0.1.1"
}

3. Rebuild and install the debug build, then pick the app in the DroidLens tool window and press ▶.

No code changes. The runtime is added to debug builds only and is completely absent from release builds. Apps that use the older android-netcapture SDK still connect, but only the Network tab works; replace kakacat.android.netcapture with kakacat.android.helper to get the Layout tab (don't apply both).

More options and troubleshooting: github.com/kakakakacat/android-helper

在 Android Studio 里直接调试运行中的 debug 包：应用层抓包（OkHttp / gRPC / WebSocket，HTTPS 明文，无需代理和证书）， 以及轻量的布局检查（截图、View / Compose 树、属性实时修改、一键跳到创建 View / 设置点击监听的代码）。 可替代 CodeLocator 和 Layout Inspector 的常用功能。

⚠ App 需要接入 SDK 才能使用。插件只负责显示，数据是 App 里的 SDK 采集的。按上面 Setup 在 settings.gradle 的两处加上仓库，在 app 模块加 id("kakacat.android.helper") version "0.1.1"， 重新安装 debug 包即可，业务代码零改动，release 包里不会有 SDK。只接了老版 netcapture SDK 的 App 只能用 Network 页， 换成 kakacat.android.helper 后才能用 Layout 页（两者不要同时应用）。
