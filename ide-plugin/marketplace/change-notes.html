0.1.3

  • No more manual setup: when you open an Android project, DroidLens adds its bundled SDK to the debug builds through a Gradle init script. Project files are not changed, nothing is downloaded, release builds are untouched. Turn it off in Settings → Tools → DroidLens.
  • Layout: selecting a custom view opens its class (can be turned off); visibility, enabled and layout_width / layout_height are edited with a drop-down.

0.1.2

  • When no app with the SDK is running, the tool window shows the setup steps with copyable Gradle snippets instead of an empty view.
  • Layout screenshots now include SurfaceView content (video, camera, OpenGL / Filament / Unity scenes) instead of a black area. Needs SDK 0.1.2.
  • The SDK records its own errors (failed screenshots, hooks that threw, Compose internals that changed) instead of failing silently; DroidLens reports them, sanitized, as public GitHub issues. Can be turned off in Settings → Tools → DroidLens.
  • Errors in the plugin itself can be reported from the IDE error dialog.

0.1.1

  • The status bar no longer stays on "Finding devices…" after a refresh while an app is connected.
  • Clearer hints when an app has no SDK or only the old netcapture SDK, and setup steps on the plugin page.

0.1.0

  • Network tab: OkHttp, gRPC and WebSocket capture with body viewers, protobuf decoding and copy as cURL.
  • Layout tab: screenshot, View and Compose trees, live property editing, jump to source.
  • Works with apps using the older android-netcapture SDK (network only).
